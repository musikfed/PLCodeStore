Уже на витрине
Безопасное разделение: эта страница статическая и не хранит GitHub-токен. Три галочки и «Пропустить на потом» сохраняются лишь в браузере. «Следующая» просто перелистывает карточки; пропущенные можно вернуть. Для публичных проектов Merge Pull Request в GitHub служит разрешением публикации: редактировать JSON и создавать Issues не нужно. После Merge карточка появляется на витрине при следующей сборке Pages. Кнопки «На доработку» и «Пропустить» сохраняют состояние локально; комментарий в GitHub отправляется только тобой. Для закрытых проектов отдельно требуется явное разрешение public_private_approved: true.
